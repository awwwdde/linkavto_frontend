# LINKAVTO

Витрина маркетплейса автозапчастей: подбор детали под свой автомобиль, сравнение
предложений разных продавцов, корзина и оформление заказа.

Это самостоятельный фронтенд — серверная часть магазина живёт отдельно и в этот
репозиторий не входит. Пока реального `/api/v1/` нет, витрина работает на моках
MSW, так что для локальной разработки бэкенд не нужен.

## Запуск

```bash
cd frontend
pnpm install
pnpm dev
```

Откроется на `http://localhost:5173`. Остальные команды:

| Команда | Что делает |
|---|---|
| `pnpm build` | `tsc --noEmit` + продовая сборка Vite |
| `pnpm typecheck` | только проверка типов |
| `pnpm lint` | ESLint |
| `pnpm msw:init` | перегенерировать service worker MSW в `public/` |

## Стек

React 19, TypeScript 5.7, Vite 6, React Router 7 (data router, страницы через
lazy), TanStack Query 5, Zustand 5, Tailwind CSS 4, React Hook Form + Zod, ky,
MSW 2, motion + GSAP + Lenis, карты на 2ГИС MapGL.

## Структура

Feature-Sliced Design, алиас `@` → `frontend/src`.

```
frontend/src/
├── app/        роутер, лэйауты, провайдеры, глобальный UI-стор
├── pages/      страницы, по одной на маршрут
├── features/   пользовательские сценарии: поиск, корзина, гараж, авторизация,
│               фильтры каталога, адреса и доставка, избранное, оформление
├── entities/   доменные сущности: товар, категория, продавец, отзыв
├── shared/     api-клиент, ui-кит, хелперы, i18n, дизайн-токены
└── mocks/      MSW: handlers + фикстуры
```

Договорённости, о которые проще всего споткнуться:

- **Деньги — всегда целые копейки.** Никаких float, форматирование только через
  хелперы из `shared/lib/format`.
- **Дизайн-токены живут в одном месте** — `src/styles/index.css`, блок `@theme`.
  В компонентах не должно быть ни hex-цветов, ни px-размеров.
- **Строгий TypeScript.** `any` и `@ts-ignore` в код не проходят.
- Анимации уважают `prefers-reduced-motion`.

## Моки

Service worker перехватывает запросы к `/api/v1/` и отдаёт фикстуры — замокан
весь контракт: каталог и дерево категорий, каскад подбора авто, карточка товара
с предложениями и отзывами, поиск, корзина, гараж, заказы, продавцы.

Переключается флагом `VITE_ENABLE_MOCKS` в `frontend/.env.development`. Когда
появится настоящий API, флаг снимается и `VITE_API_BASE_URL` направляется на
боевой origin — переписывать вызовы не придётся, типы контракта уже описаны.

Чего фронту не хватает от бэкенда — списком в
[frontend/API_REQUESTS.md](frontend/API_REQUESTS.md). Места, ждущие реальную
ручку, помечены в коде `TODO(api)`.

## Сборка образа

```bash
docker build -t linkavto .
docker run --rm -p 8080:8080 linkavto
```

Многостадийная сборка: Vite → nginx, контейнер слушает `:8080`, готовность
проверяется через `GET /healthz`.

Переменные окружения в рантайме не читаются — сборка статическая, всё нужное
вшивается на этапе `vite build`. Секреты в этот репозиторий не коммитятся:
в `.env`-файлы попадает только публичная конфигурация сборки.
